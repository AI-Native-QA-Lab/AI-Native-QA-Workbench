# 技术栈

## Core

TypeScript 5.x、Node.js 20+、pnpm、Turborepo。

## Frontend

React、Vite、React Router、shadcn/ui + Radix UI、Tailwind CSS、TanStack
Query、Zustand、i18next。

## Backend

Fastify、Zod、JSON Schema、SSE。

## Storage

项目质量数据使用 Markdown/YAML/JSON；Runtime State 使用 better-sqlite3 +
SQLite；大型 Artifact 保留在 Filesystem。PostgreSQL 仅作为未来 Optional
Shared Workbench 能力。

## Testing

Vitest、Testing Library、Playwright、MockProvider、Contract Test
Suites。

## v0.x Non-goals

Redis、Kafka、Required PostgreSQL、Complex ORM、Vector DB、Object
Storage、Kubernetes。
